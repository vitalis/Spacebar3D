## Найдите. Нажмите пробел. Поверните.

Выберите поддерживаемый 3D-файл в Finder и нажмите <kbd>Пробел</kbd>. Поверните модель, изучите топологию, смените стиль или просмотрите анимацию. Откройте файл в приложении, если нужно отдельное окно просмотра.

<p align="center">
  <img src="../demo.gif" width="900" alt="Модель танка в Spacebar 3D с видимыми элементами управления">
</p>

> Для OBJ, STL, PLY, USD и USDZ macOS может выбрать собственный предпросмотр. **Файл → Открыть…** или **Открыть в программе → Spacebar 3D** в Finder откроет любой поддерживаемый файл в этом просмотрщике.

<a id="looks"></a>

## Одна модель, множество образов

| Изучайте | Экспериментируйте | Воспроизводите |
| :--- | :--- | :--- |
| Виды «Сплошной», «Текстуры» и «Нормали»; наложение каркаса; количество граней и вершин. | Стили без затенения, аниме, сел-шейдинг, ретро, воксельная графика и голограмма; плоское или сглаженное затенение и настройки материалов. | Выбор клипов, перемотка и повтор; показ скелета для поддерживаемых файлов только с анимацией. |

**Настройте свет.** Семь вариантов освещения от Glasshouse до Neon, яркость, направление и автоматическое вращение света. **Не теряйте ориентир.** Нажмите на ось гизмо, вращайте и перемещайте модель, впишите её в окно или включите сетку пола. В маленьких предпросмотрах Finder отображается только модель.

**Нативное приложение для Mac.** Swift, Metal, SwiftUI и AppKit используются и в приложении, и в расширении Quick Look. Модели обрабатываются локально; у обоих компонентов нет разрешений на сетевые подключения. Интерфейс поддерживает десять языков из списка вверху и следует языковым настройкам macOS. [О локализации, на английском](../LOCALIZATION.md).

## Начало работы

**macOS 26 или новее · Apple silicon · сборка из исходников**

Нужны полная версия Xcode с SDK для macOS 26 или новее, XcodeGen, CMake и Ninja. В проекте заданы команда разработчиков для подписи и App Group. Если вы используете другую команду, перед сборкой настройте подпись и связанные идентификаторы по [инструкции по подписи](DEVELOPMENT.md#build-local).

Из локальной копии репозитория:

```bash
brew install xcodegen cmake ninja
./scripts/build.sh
```

При первой сборке скачивается и собирается закреплённая версия Assimp.

1. Переместите `build/Build/Products/Release/Spacebar 3D.app` в **Программы**.
2. **Запустите приложение один раз**, чтобы зарегистрировать расширение.
3. Включите **Spacebar 3D** в **Системные настройки → Основные → Объекты входа и расширения → Быстрый просмотр**.
4. Выберите поддерживаемый файл в Finder и нажмите <kbd>Пробел</kbd>.

Для распространения сборки следуйте [инструкции по подписи Developer ID и нотарификации](DEVELOPMENT.md#distribution-signing--notarization).

<details>
<summary><strong>Назначить Spacebar 3D приложением по умолчанию</strong></summary>

В настройках приложения нажмите **Назначить по умолчанию…**. macOS может запросить подтверждение; приложение сообщит о форматах, для которых смена не удалась. Это влияет на открытие двойным щелчком в Finder, но не на выбор расширения Quick Look.

</details>

## Поддерживаемые форматы

Аватары, игровые ресурсы, экспорт из CAD, сканы и сетки Blender.

`VRM` · `VRMA` · `glTF` · `GLB` · `FBX` · `OBJ` · `STL` · `3MF` · `PLY` · `USD` · `USDA` · `USDC` · `USDZ` · `3DS` · `BLEND`

<details>
<summary><strong>Возможности и ограничения каждого формата</strong></summary>

| Формат | Поддержка |
| :--- | :--- |
| `.vrm` | Аватары VRM 0.x / 1.0: toon shading, контуры и spring bones. |
| `.vrma` | Анимация VRM без сетки; движение показывается на схематичной фигуре скелета. |
| `.glb` / `.gltf` | glTF 2.0 с материалами, текстурами, скиннингом и анимациями. Внешние `.bin` и изображения требуют доступа к папке. Draco, Meshopt и инстансированные сетки не поддерживаются. |
| `.fbx` | Двоичный или текстовый; сетки со скиннингом и встроенные анимации. Изображения внутри файла, рядом с ним или в папке `.fbm`. |
| `.obj` | Геометрия и цвета вершин; материалы и текстуры из `.mtl` после разрешения доступа к папке. Файл без граней отображается как облако точек. |
| `.stl` | Двоичный или текстовый STL. |
| `.3mf` | Цвета по объектам или треугольникам, изображения, металлические и полупрозрачные материалы. |
| `.ply` | Сетки с цветами вершин или облака точек, если нет граней. |
| `.usd` / `.usda` / `.usdc` / `.usdz` | Материалы, встроенные текстуры и скелетная анимация. |
| `.3ds` | Цвета и прозрачность материалов; внешние текстуры после разрешения доступа к папке. |
| `.blend` | Blender 2.80 и новее: видимые сетки и базовые материалы в сохранённом виде; упакованные изображения и текстуры из разрешённой папки. Модификаторы, позы арматуры и анимации не применяются; произвольные сети узлов шейдеров не вычисляются. |

FBX только с анимацией и VRMA с поддерживаемым скелетом отображаются как схематичные фигуры. Данные моделей и аватаров не входят в приложение.

</details>

### Текстуры в отдельных файлах

Нажмите **Показать текстуры…**, **Показать материалы…** или **Показать модель…**, чтобы разрешить доступ только для чтения к папке модели и её подпапкам. Встроенные текстуры не требуют такого разрешения, но должны использовать поддерживаемые форматы изображений и материалов. В приложении одноимённый файл материала, например `ship.mtl` рядом с `ship.obj`, может быть прочитан без запроса.

Если модель открывается, но ни одну из указанных в ней текстур отрисовать не удаётся, просмотрщик переключается с режима **Текстуры** на режим **Сплошной**.

## Управление

| Действие | Способ |
| :--- | :--- |
| Вращение | Перетаскивание или стрелки, когда область модели в приложении в фокусе |
| Перемещение | Перетаскивание правой кнопкой мыши или с зажатой Shift, Option либо Command |
| Перемещение с клавиатуры | Shift + стрелки в области модели или подменю перемещения в меню «Вид» |
| Масштаб | Прокрутка или жест сведения/разведения пальцев |
| Вписать модель в окно | Кнопка вписывания или ⌘0 в приложении |
| Взгляд вдоль оси | Щелчок по оси гизмо |
| Воспроизведение / пауза | Кнопка воспроизведения или пробел, когда область модели в приложении в фокусе |
| Закрыть Quick Look | Пробел |
| Сплошная заливка / Текстуры / Нормали | ⌘1 / ⌘2 / ⌘3 в приложении |
| Каркас | ⌘4 в приложении |

Внизу находятся виды, стили и материалы; справа — гизмо, свет, вписывание, сетка и автоматическое вращение. Панель анимации позволяет выбирать и повторять клипы. В настройках задаются фон, цвет заливки, вид, яркость, сетка, вращение и воспроизведение. Меню вида и воспроизведения доступны и при скрытых элементах управления на модели.

<a id="help"></a>

## Если нужна помощь

Откройте меню **?** на панели инструментов, чтобы посмотреть справку по управлению, политику конфиденциальности и благодарности. Меню доступно в приложении и в Quick Look.

Нашли ошибку или есть вопрос? В приложении выберите **Справка → Поддержка Spacebar 3D** или [создайте issue](https://github.com/vitalis/Spacebar3D/issues).

<details>
<summary><strong>Предпросмотр не появляется</strong></summary>

Запустите приложение один раз и включите расширение. При необходимости обновите кеш Quick Look:

```bash
qlmanage -r && qlmanage -r cache
```

OBJ, STL, PLY, USD и USDZ попробуйте открыть непосредственно в приложении.

</details>

<details>
<summary><strong>Предпочитать Spacebar 3D встроенным предпросмотрам Apple</strong></summary>

Необязательное переключение можно отменить:

```bash
scripts/prefer-spacebar3d.sh status
scripts/prefer-spacebar3d.sh on
scripts/prefer-spacebar3d.sh off
```

`on` отдаёт предпочтение Spacebar 3D, `off` восстанавливает расширения Apple. Скрипт отключает два расширения Apple для вашей учётной записи через `pluginkit`, не меняя системные файлы. При этом MaterialX и Alembic получают упрощённый предпросмотр, USDZ теряет режим AR, а `.reality` остаётся без предпросмотра. Обновление macOS может сбросить выбор. Для открытия файлов в приложении это переключение не требуется.

</details>

<details>
<summary><strong>Не видны текстуры</strong></summary>

Разрешите доступ к папке через **Показать текстуры…**. Разрешение, выданное только в Quick Look, нужно повторить после перезапуска Mac. Приложение запоминает свои разрешения; один запуск после перезагрузки снова делает их доступными Quick Look. Отсутствующие изображения и неподдерживаемые форматы изображений или материалов могут мешать отображению текстур.

</details>

## Как это устроено

Приложение и расширение используют общий `Spacebar3DKit`: `ImportRouter` читает файл в `ModelScene`, затем Metal рисует модель. Читатели на Swift обрабатывают STL, PLY, OBJ, 3MF, glTF, VRM и Blender; Model I/O — USD; Assimp — FBX и 3DS.
